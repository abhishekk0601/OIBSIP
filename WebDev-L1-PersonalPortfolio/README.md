# Personal Portfolio

OIBSIP - Web Development and Designing - Level 1 - Task 2

My personal portfolio website. It shows who I am, my skills, my projects, and how to contact me.

## Built with
- HTML5
- CSS3 (Flexbox, Grid, CSS variables)
- Vanilla JavaScript for small enhancements (`script.js`)

## Checklist
- Hero section: name, role title, and photo
- About Me section (3 sentences)
- Skills grid: HTML, CSS, C, Python, Java, video editing
- Projects section: 2 project cards with title, description, and GitHub link
- Contact section: name, email, LinkedIn, GitHub
- Smooth scroll navigation between sections
- Same colours and fonts on the whole page
- Responsive: works on desktop and mobile

## Dynamic features
- Hero background: a moving network of nodes. Amber dots travel between the nodes, and the nodes move away from the mouse
- Typing effect for the words after "I enjoy"
- The nav link of the current section is highlighted
- Menu button on mobile screens
- Footer year updates by itself
- Smooth scrolling between sections

The page still works if JavaScript is turned off. The animations stop for people who turned on "reduce motion" in their system.

## How to run
Open `index.html` in any browser.
