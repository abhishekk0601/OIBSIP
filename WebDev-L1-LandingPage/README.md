# LootDeals2x Landing Page

OIBSIP - Web Development and Designing - Level 1 - Task 1

A responsive landing page for my Telegram deals channel, **LootDeals2x**.

## Built with
- HTML5
- CSS3 (Flexbox, CSS variables, `clamp()` for text size)
- No JavaScript

## Checklist
- Sticky navigation bar with 4 links
- Hero section: headline, subheadline, call-to-action button
- 2 content sections: "What you get" and "How it works"
- Footer with contact and social links
- One colour palette used on all sections
- Works on mobile screens (tested by shrinking the browser window)
- 2 text sizes: headings and body text

## How to run
Open `index.html` in any browser.
